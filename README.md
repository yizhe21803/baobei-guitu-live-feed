# 宝贝归途 · 官方公开寻亲资料同步服务

本仓库**仅存放代码与自动化任务，不把儿童档案或照片提交到 Git 历史**。
GitHub Actions 定时低速访问原始公开列表和详情，校验成功后原子发布 GitHub Pages 数据文件。
任何列表页失败、非 404 的详情错误或异常数量均会中止发布。
此服务不宣称公开登记档案中的人物当前仍然失踪。

部署入口：https://yizhe21803.github.io/baobei-guitu-live-feed/data/latest.json

- 每 12 小时尝试更新一次
- 发布数据过期时间为生成后 30 小时
- 不永久缓存照片，照片由 iOS 端按需从官方域名获取
- 如需停止分发，可禁用 GitHub Pages，发布空列表或移除整个部署
- 数据更新与 Apple App Store 审核无直接关系
